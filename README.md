** For front end its a angular application.

1- once you open the project you need to pull all remote change by typing git pull origin main.<br>
2- once you open it in terminal you need to type npm install to download all the needed packages.<br>
3- to start the application on localhost you need to type the command ng serve --no-hmr.<br>
4- if you change anything in the repo you need to create a new branch and then make a PR on github.<br>
