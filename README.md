### For front end its a angular application.

1- once you open the project you need to pull all remote change by typing  <code>git pull origin main </code>.<br>
2- once you open it in terminal you need to type  <code> npm install </code> to download all the needed packages.<br>
3- to start the application on localhost you need to type the command  <code> ng serve --no-hmr </code>.<br>
4- if you change anything in the repo you need to create a new branch and then make a PR on github.<br>
